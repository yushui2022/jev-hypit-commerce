# Advanced creator network scene

A 42-second Hypit scene owns the Chinese network thesis, Jev/Hypit mechanism cards, product-to-creator pairing, four real generated-video viewports, and a 12 / 36 / 99-node depth matrix.

`activation.ts` declares all image and video inputs. `render.ts` uses typed text with pinned fonts, typed video elements with explicit 30fps sampling, and a deterministic HyperFrames browser program. `content.ts` holds the saved product/profile/portrait assignments.

Videos are normalized by `productions/advanced/export.py`. Each selected 3-second excerpt has the same source trim in `render.ts` and the SVML audio track; change both when changing excerpts. The rest of the composition is frame-addressable in Studio.

See [production instructions](../../productions/advanced/README.md).
