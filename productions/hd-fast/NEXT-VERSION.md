# 下一版创意方案（尚未制作）

创意方向：一件商品触发匹配，找到数字达人，再展开为整个达人网络。

- 0–1 秒：大商品图与唯一说明「为商品，匹配 AI 数字达人」。
- 1–5 秒：商品居中，人物卡快速掠过，选中人物放大并与商品并排。
- 5–10 秒：商品与人物通过颜色和轮廓呼应切换；主商品稳定可读，背景快速跳动。
- 10–16 秒：镜头拉远为有纵深的大矩阵，按波浪、对角线和中心扩散产生灯光变化。
- 16–22 秒：镜头穿越矩阵，三联屏、九宫格、百人墙逐渐加速，中途短暂停顿后爆发。
- 22–26 秒：矩阵收拢，贯一科技与真实 GitHub 地址落版，地址稳定停留约 2 秒。

视觉建议：石墨黑、暖白、电光青；保持真实商品图清晰，增加少量人物动态素材。后续人物动作需另行制作。

音乐建议：约 132 BPM 的 UK Garage / 电子碎拍，厚实低音、少量人声切片与匹配音效。先试听候选，再做 8 秒视觉样片验证。具体音乐尚未选定。

交付要求：更新本仓库的 Hypit 源工程、素材说明、复现方法和成片 MP4；每个已完成版本保留独立目录或发布记录。
